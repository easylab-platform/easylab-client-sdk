# easylab-sdk-go

EasyLab typed client SDK for Go — **buf-generated re-exports only** of the
easylab.v1 + worker.v1 Connect clients and message types. No hand-written
transport, auth, or wrapper.

For the clients themselves import the generated packages directly:

```go
import (
    "net/http"

    "connectrpc.com/connect"
    easylabv1 "github.com/easylab-platform/easylab-proto/easylab/v1"
    "github.com/easylab-platform/easylab-proto/easylab/v1/easylabv1connect"
)

func main() {
    protocols := new(http.Protocols)
    protocols.SetHTTP1(false)
    protocols.SetUnencryptedHTTP2(true) // h2c
    hc := &http.Client{Transport: &http.Transport{Protocols: protocols}}

    lab := easylabv1connect.NewLabServiceClient(hc, "http://easylab:80",
        connect.WithInterceptors(auth("devtoken")))
    _ = lab
}
```

This package exists only so consumers have the common names (message/request
aliases + service constructors) under one import. Generated by buf from
[easylab-platform/proto](https://github.com/easylab-platform/proto).
